Payment Gateway-based Charges

Implementation of Dynamic Payment Gateway-Based Charges

This feature enables the calculation and application of additional fees (e.g., transaction fees, service charges) based on the selected payment gateway during the checkout process.

  • Charges are dynamically applied in the shopping cart.
  • Customers see a transparent breakdown of applied fees during checkout.
  • All charges are accurately recorded in the backend for order processing and reporting.

This ensures both clarity for customers and accuracy for administrators when handling payment gateway-related costs.
