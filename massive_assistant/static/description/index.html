Asistente Massive Connector

Tu asistente de IA dentro de Odoo, con chat flotante y herramientas para trabajar con tus datos.

Versión inicial para validación en una base de pruebas. La instalación y los flujos deben verificarse en cada versión y edición antes de producción.

Funciones

  • Chat minimizable, icono y encabezado arrastrables.
  • Productos, conteos completos, stock, ventas, compras, inventario y contabilidad según permisos.
  • Listas XLSX/CSV, vistas previas y confirmación antes de modificar precios.
  • Presupuestos borrador y cambios acotados de códigos/descripciones.
  • Vinculación individual: cada usuario usa SU clave API y sus permisos Odoo.

Requisitos y consumo

Requiere cuenta habilitada en Massive Connector y cuenta API de OpenAI configurada y financiada por la empresa. El consumo de IA corresponde a esa cuenta. No incluye créditos de IA ni utiliza créditos de IA de Odoo.

Instalable en Odoo.sh o servidor propio con módulos Python, HTTPS y cryptography. No instalable en Odoo Online. Descargar el paquete de la versión exacta de Odoo.

Datos temporales

No guarda conversaciones ni archivos en Odoo. Conserva una vinculación cifrada y temporal por usuario. Massive Connector procesa consultas y propuestas con retención limitada; las operaciones inciertas requieren revisión.

Configuración

  1. Instalar en una base de pruebas y asignar el grupo Asistente Massive · Usuario.
  2. Conectar el ERP en Massive Connector, seleccionar versión y configurar la IA de la empresa.
  3. Abrir el icono del chat, ingresar la propia clave API Odoo y solicitar autorización al propietario de Massive Connector.
  4. Completar vinculación y probar primero consultas de lectura.
